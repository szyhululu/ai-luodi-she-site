按账号能力选择

-   任务需要频繁看命令输出：选 CLI。
-   任务需要多个 agent 并行、Skills 或定时任务：选择 ChatGPT 桌面 App。
-   任务时间较长、希望后台跑、可能生成 PR：选 Cloud / Web。
-   你正在编辑具体文件：选 IDE。VS Code、Cursor、Windsurf 使用 Codex 扩展，Xcode 和 JetBrains 使用各自的集成。
-   你想随时查看或继续 Cloud 任务：选 ChatGPT Web / Mobile。
