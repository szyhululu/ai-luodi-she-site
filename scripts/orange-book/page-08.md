## WorkBuddy 与 Codex/Cursor/Claude Code 的区别

### 🖥️ Codex

生态里的多端工程 Agent。聚焦编程场景，通过 CLI、App、IDE Extension、OpenAI 执行软件工程任务。

> Web · 代码工程Agent Git工作流

### ⌨️ Cursor

进入陪你写代码、做局部修改、跨文件重构。AI 编辑器，让 AI IDE

> 编辑器局部修改 IDE协作

### 💻 Claude Code

终端里的长期工程搭档。擅长深度上下文协作、复杂任务持续追踪。

> 终端长期协作复杂工程

### 🔥 WorkBuddy

全场景 AI 办公工作台。覆盖职场全场景：文档、数据、PPT、自动化、多 Agent、跨平台远程操控。从"编程助手"升级为"职场同事"。

> AI · 全场景办公自动化多Agent 跨平台

怎么选如果你主要做编程：Codex+Cursor 是很好的编码搭档。如果你需要终端里长期工程协作：Claude Code 很适合。
