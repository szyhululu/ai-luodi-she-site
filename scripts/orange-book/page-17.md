记忆系统的价值：

Cloud Memory 跨会话、跨 WorkBuddy 自动学习你的习惯和偏好，长期沉淀。无需手动维云记忆项目护。User-level 所有项目共你明确要求记住的个人偏好、规则、习惯。存于 Memory 享~/.workbuddy/MEMORY.md 用户级记忆 Workspace 每日工作日志+项目长期笔记。记录项目进展、技术决策、经验 Memory 当前项目教训。工作区记忆

- WorkBuddy 用久了，它会越来越懂你的工作方式和偏好
- 不需要每次重复交代项目背景和规则
- 跨会话的任务有连贯性，不会"失忆"
- 你可以随时查看和手动管理记忆内容

## 多模态内容生成

WorkBuddy 不只是处理文本。它支持多模态内容的生成：

| 能力 | 说明 |
|---|---|
| 文本生成图像 | 用文字描述，生成对应图片 |
| 文本生成视频 | 用脚本描述，生成视频内容 |
| 文本生成3D模型 | 描述物体，生成3D模型 |
| 图片生成3D模型 | 上传图片，转为3D模型 |
| 图片/视频特效 | 对图片或视频应用 AI 特效 |
