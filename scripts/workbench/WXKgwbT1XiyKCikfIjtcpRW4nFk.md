**个人生活工作台开发提示词**

可直接与附件 HTML 一起发送给编程 Agent

**请基于本次对话中附带的 HTML 文件，直接开发一个可运行的个人生活工作台。附件 HTML 是已经确认的正式 UI，不是普通参考图。**

## 一、UI 与开发原则

先完整读取并运行附件 HTML，再直接在原 HTML、CSS 和布局基础上继续开发。

保留原页面的云雾背景、整体布局、卡片排列、左侧导航、顶部问候、快速记录区域、配色、圆角、阴影、透明度、字体层级、图标风格和底部快捷操作。

左上角品牌区域保持留空，不显示默认产品名或个人姓名。

不要重新设计首页，不要替换成 SaaS Dashboard、Admin 后台或其他模板。

首页只展示各功能的简洁摘要，点击卡片或导航后进入独立功能页面，所有页面延续附件 HTML 的视觉风格。

## 二、功能模块

记账：收入、支出、分类、日期、备注、编辑、删除和月度统计。

每日一句：换一句、收藏、复制和分享。

外语学习：单词、短句、发音、释义、例句和学习进度。

减脂计划：BMR、TDEE、每日目标热量、饮食、运动和体重记录。

星座运势：十二星座及今日、明日、本周运势。

新闻资讯：分类、摘要、来源、原文链接和收藏。

天气：城市、温度、湿度、风力、空气质量和未来天气。

播客推荐：RSS、播放、暂停、进度和收藏。

记事本：新增、编辑、删除、置顶、标签、搜索和自动保存。

## 三、技术与数据

优先使用原生 HTML、CSS、JavaScript，并配合 FastAPI、SQLite 和 WebSocket。

原附件 HTML 直接作为 static/index.html，不要为了使用 React、Vue、Tailwind 等框架而重写原页面。

核心数据保存到 data/app.db，不能只使用 localStorage。

电脑和手机访问同一个服务和同一个数据库。

前端 API 使用 /api/... 相对路径，WebSocket 根据当前网页地址自动生成，禁止写死 localhost 或 127.0.0.1。

## 四、移动端与同步

手机端不能只是缩小桌面页面，应改为单列卡片、底部导航和适合触摸的交互，同时保持相同的背景、配色、卡片和动效风格。

电脑和手机连接同一个 Wi-Fi 后，手机通过电脑局域网 IP 访问。

任一设备新增、编辑或删除数据后，通过 WebSocket 自动同步到其他设备；WebSocket 断开时使用定时刷新作为降级方案。

手机端需要避免横向滚动、文字溢出、按钮裁切和虚拟键盘遮挡。

## 五、一键启动

项目根目录提供“启动工作台.bat”“停止工作台.bat”和 README.md。

普通用户双击“启动工作台.bat”后，自动安装缺失依赖、初始化数据库、检测局域网 IP、检测可用端口、启动服务并打开电脑网页。

启动成功后显示电脑访问地址、手机访问地址和手机访问二维码。

服务监听 0.0.0.0，默认使用 8000 端口；端口被占用时自动选择其他可用端口。

用户不需要手动执行 pip install、uvicorn、python main.py、ipconfig 或其他开发命令。

## 六、交付与测试

直接生成完整可运行项目，不要只输出方案、伪代码或重新设计的页面。

实际测试原 HTML 是否被真实使用、UI 是否基本保持一致、手机端是否正常、手机能否通过局域网 IP 访问、数据刷新后是否保留、手机和电脑是否实时同步。

检查页面是否存在遮挡、横向溢出、资源加载失败或本机绝对路径。
